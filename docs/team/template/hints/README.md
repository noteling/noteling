# Hints

A hint is a line someone left on a control with Noteling's pen, for the next person who meets it. Noteling keeps each
as one JSON file; sharing one from Noteling opens GitHub with the file ready to add here. Commit it, or merge the pull
request, and everyone who links these tools sees it on that control within ten minutes.

A hint's file says where it is met: its page's key, or a `pattern` such as `www.walmart.com/ip/*/*` when it is for
every page of a kind, as the paper's **Pages like this** writes it (`*` stands for a part of the address that names
one item). A Noteling from before patterns reads the page alone.

Only `.json` files count; this README is ignored.
